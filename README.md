##  How I Take Notes

For each problem, I try to write down:

- What the problem is asking
- My understanding of the problem
- The approach I used
- Why the approach works
- Important things to remember
- Time and space complexity
- The code

I'm trying to write things in my **own words** instead of just copying solutions.
